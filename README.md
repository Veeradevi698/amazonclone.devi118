# Amazon Clone – Frontend E‑Commerce Website

A responsive **Amazon Clone frontend** built using **HTML, CSS, and JavaScript**.  
This project replicates the core design and functionality of Amazon’s shopping interface, focusing on **UI/UX design, responsive layouts, and interactive components**.
#  Features
-  **Homepage Layout** – Navigation bar, search bar, product categories  
-  **Product Catalog** – Grid-based product listings with hover effects
-  **Responsive Design** – Optimized for desktop, tablet, and mobile  
-  **Modern Styling** – CSS animations, transitions, and hover effects
-  ## Tech Stack
- **HTML5** – Semantic structure  
- **CSS3** – Flexbox, Grid, animations  
- **JavaScript (ES6)** – event handling 
##  Objectives
- Practice **frontend development** with real-world e‑commerce design  
- Strengthen skills in **responsive web design** and **UI/UX principles**  
- Build a **portfolio-ready project** showcasing web development skills
